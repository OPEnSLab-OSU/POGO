# POGO

Remote drone gel dispenser repository.

Work-in-progress comprehensive remote dispensing controls supporting various controllers for DC motors or steppers and analog switches, etc. 

Use WiFi, BLE, or MQTT via LTE for remote control of an ESP32S3 with a convenient browser app either on the device, remote-hosted, or run locally for BLE.

This will be fully documented when we've settled on the driver specifics and have the full routine ready to go.
